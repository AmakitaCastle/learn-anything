# 本地 Web Demo

Web Demo 把终端中的“输入主题 → 生成材料 → 编译课程 → 本地播放”主链路放进一个页面。它复用现有宿主工作流和独立播放器，不把模型、TTS、文件系统或 FFmpeg 移进浏览器。

## 启动

安装 Node.js ≥22.13 和项目依赖：

```bash
npm ci
npm run web
```

命令会构建本地页面、启动仅监听 `127.0.0.1` 的任务服务并打开浏览器。不能自动打开时，使用终端打印的随机地址。可用 `npm run web -- --no-open` 禁止自动打开，或追加 `--port 4318` 固定端口。

页面中的“先看示例”无需 API Key、FFmpeg 或语音缓存。生成新课程需要先按 [README](../README.md) 配置 `.env.local`，并安装 FFmpeg／FFprobe。环境卡片只返回“已配置／待配置”，不会把配置值发送给页面。

## 页面操作

1. 填写主题，选择受众、目标时长和讲解段落。
2. 确认本次操作可能调用文本模型和语音服务并产生费用。
3. 点击“生成一堂课”，查看环境检查、材料生成、课程编译和播放器准备进度。
4. 完成后在当前页面试听、拖动、倍速和重播，也可以在独立窗口打开课程。

同一时间只运行一个任务。生成中可以取消；已经写入运行目录的材料不会删除。生成结果仍保存在 `outputs/runs/`，格式与 `npm run lesson` 完全相同。知识正确性、听感和低置信度词需要人工复核。

## 安全与产品边界

- 服务只绑定 `127.0.0.1`，使用每次启动随机生成的访问路径并校验 Host。
- 密钥只由 Node 宿主从忽略的 `.env.local` 读取；页面不能读取或修改密钥。
- 付费生成需要页面中的显式确认；示例播放不会调用模型或语音服务。
- 接口只接受受约束的主题、受众、段落和时长，不接受文件路径或任意命令。
- 页面资源、任务接口和课程播放器都使用封闭资源列表，不提供目录浏览。
- 模型输出继续经过 `LessonDraft` 校验，只能引用已注册的动画能力，不执行生成的 HTML、JavaScript 或组件。
- 这是本机单用户制作工具，不是公网账户服务。账号、数据库、在线分享、文件上传和多人任务不在第一版范围内。

CLI 仍然是批处理、缓存恢复、视频导出和高级兼容参数的完整入口，见[终端使用指南](./terminal-lesson.md)。
