# learnAnything v0.1.0-demo.1

输入主题，从终端生成一堂包含旁白、动态板书和概念动画的本地课堂。

本版流水线：LLM → LessonDraft 0.1.0 → compileLessonDraft() → MP3、LessonSpec 0.1.0、VTT → lesson-player。

## 本次修订

修复 Linux 下新生成 MP3 的编码填充造成课程时长多出约 0.06 秒、跳转结尾无法到达声明终点的问题。编译器以实际 PCM 采样时长确定课程终点；协议版本仍为 0.1.0。另修复干净 Linux 环境的模块检查顺序与独立包消费测试的冷缓存安装。

## 快速体验

下载并解压源码，在项目目录运行：

```bash
npm ci
npm run demo
```

需要 Node.js ≥22.13。自带升温曲线课无需 API Key、FFmpeg 或缓存，安装依赖后可离线播放。浏览器中点击“播放”，终端按 Ctrl+C 退出。

## 生成新课程

安装 FFmpeg／FFprobe，把 `.env.example` 复制为 `.env.local`，分别填写文本模型与豆包语音配置后：

```bash
npm run lesson -- "水循环" --generate
```

`--generate` 允许接口请求，可能消耗额度；不带它只预检。完整安装、配置、产物与恢复见 README 和 docs/terminal-lesson.md。

## 本版能力

- 主题备课、材料校验、语音编译、本地保存与播放。
- 全文板书、图文跟随、局部重点圈画。
- 数组查找、流程、状态转换和曲线动画。
- 暂停、seek、倍速、静音、重播与确定性状态恢复。
- 已保存课程离线重播，编译失败后从材料恢复。

## 已知限制

实验性 Demo，生成知识、听感和低置信度语音词需人工审核。注册式动画和字体路径不代表所有学科泛化或规范汉字笔顺。多模型协议通过离线合同测试，不代表全部厂商／账号均已实测。macOS 已本地验证；Linux CI 与 GitHub 发布状态以实际运行结果为准，Windows 未做实机验收。

项目原创代码采用 Apache-2.0，第三方资源保留原许可证。第一版通过 GitHub 源码分发，尚未发布 npm 全局命令或公网服务。
